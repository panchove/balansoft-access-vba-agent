# 014 — Internacionalización de la UI (i18n)

> **Norma de referencia:** ISO/IEC 29148:2018 (Requirements Engineering) / ISO/IEC 25010:2023 (Usabilidad)  
**Estado:** `implementado`  
**PRD:** FR-13  
**ADRs:** ADR-001  

---

## Contexto

La Terminal NIM (WinForms) muestra todos sus textos en español codificados directamente en el código fuente. No hay mecanismo para cambiar el idioma ni para soportar otros idiomas. El spec 011 (SESSION-MANAGEMENT) y otros specs asumen textos en español sin mecanismo de localización.

---

## Alcance

**Entra:**

- Clase `BlsStrings` con proveedor de textos localizados por clave.
- Idiomas soportados: español (`es`), inglés (`en`), portugués (`pt`), francés (`fr`).
- Idioma por defecto: español (`es`).
- Fallback automático a español si una clave falta en el idioma actual.
- Cambio de idioma en tiempo de ejecución sin reiniciar la Terminal.
- ComboBox de selección de idioma en la barra de sesiones de la Terminal.
- Todos los textos visibles de la Terminal usan `BlsStrings.Get(...)`.

**No entra:**

- Archivos de recursos `.resx` o dependencias de localización de .NET.
- Traducción de logs internos (solo textos de UI).
- Detección automática del idioma del sistema.
- Persistencia del idioma seleccionado entre sesiones de la Terminal.

---

## Requisitos

### R001 — Proveedor de textos localizados

Existe una clase `BlsStrings` con un método estático `Get(string key, params object?[] args)` que devuelve el texto localizado para la clave dada en el idioma actual, aplicando `string.Format` con los argumentos opcionales.

### R002 — Idiomas soportados

El proveedor soporta al menos `es`, `en`, `pt` y `fr`. Existe un método `IsLanguageSupported(string language)` para validar un código de idioma.

### R003 — Idioma por defecto y fallback

El idioma por defecto es `es`. Si una clave no existe en el idioma actual, se devuelve la versión en español. Si no existe en ningún idioma, se devuelve la propia clave.

### R004 — Cambio de idioma en tiempo de ejecución

El idioma puede cambiarse asignando `BlsStrings.CurrentLanguage` a un código válido. El cambio afecta inmediatamente a las llamadas posteriores a `Get`.

### R005 — Textos de la Terminal localizados

Todos los textos visibles al usuario en `BlsNimTerminal` (título, botones, estados, tooltips, prompts de comandos rápidos, mensajes de error, encabezados de columnas) se obtienen mediante `BlsStrings.Get(...)`.

### R006 — Selector de idioma en la UI

La Terminal dispone de un `ComboBox` en la barra de sesiones que permite seleccionar entre los idiomas soportados. Al cambiar la selección, todos los textos de la UI se actualizan inmediatamente.

## Criterios de aceptación

```
Dado que el idioma actual es español
Cuando se solicita BlsStrings.Get("AppTitle")
Entonces se devuelve "NIM Terminal"

Dado que el idioma actual es inglés
Cuando se solicita BlsStrings.Get("BtnNewSession")
Entonces se devuelve "+ New"

Dado que el idioma actual es portugués
Cuando se solicita BlsStrings.Get("BtnDeleteSession")
Entonces se devuelve "Excluir"

Dado que el idioma actual es francés
Cuando se solicita BlsStrings.Get("StatusReady")
Entonces se devuelve "Prêt"

Dado que el idioma actual es inglés y se solicita una clave que solo existe en español
Entonces se devuelve el texto en español (fallback)

Dado que se asigna BlsStrings.CurrentLanguage = "fr"
Cuando se solicita BlsStrings.Get("AppTitle")
Entonces se devuelve "NIM Terminal"

Dado que el usuario selecciona otro idioma en el ComboBox de la Terminal
Cuando el cambio se confirma
Entonces todos los textos visibles de la Terminal se actualizan al nuevo idioma
```

## Desviaciones y riesgos

- No hay persistencia del idioma seleccionado entre reinicios de la Terminal; siempre comienza en español.
- No hay pruebas de UI que verifiquen que el ComboBox de idioma refleje visualmente el cambio; solo pruebas unitarias de `BlsStrings`.
- Los textos en portugués y francés son traducciones iniciales y pueden requerir revisión por hablantes nativos.
- La clave `MsgSoloEspanol` existe solo en español como marca de prueba de fallback.
